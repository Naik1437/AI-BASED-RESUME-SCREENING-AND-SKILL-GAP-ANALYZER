# AI-Based Resume Screening and Skill Gap Analyzer

## 📌 Overview
This project is an AI-based system that analyzes resumes by extracting skills and comparing them with job descriptions to generate a match percentage and identify missing skills.

## 🚀 Features
- Skill extraction using NLP (SpaCy + NER)
- Semantic similarity using BERT
- Match percentage calculation
- Missing skills detection
- Role-based login (Admin, HR, Student)

## 🛠️ Technologies Used
- Java (JSP, Servlets)
- Apache Tomcat
- Python (FastAPI)
- SpaCy (NLP)
- BERT (Sentence Transformers)
- MySQL

## ⚙️ How It Works
1. User uploads resume
2. Java backend sends data to Python API
3. Python extracts skills using SpaCy
4. BERT calculates similarity
5. Results stored in MySQL
6. Output shown to user

## 📂 Project Structure
- java-backend → Java code
- python-ai → AI processing
- database → SQL files
